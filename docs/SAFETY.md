# 安全与风险

## ADR-011：用户自担风险启用本地实机输入

[enza 利用规约](https://enza.fun/menu/terms) 禁止用工具不正当推进游戏，违反时可能被限制功能或停用账号。MaaShinyColors 向自带的游戏窗口发送点击，是使用者知悉这一点后自行选择承担账号风险的结果，不是运营方的许可。

`project_policy.json` 的 `risk_acceptance_reference` 指向本节。把其中的 `live_input_enabled` 改为 `false`，程序就不再向游戏发送任何点击，只识别画面。

## 点击规则

- 只在本机、只向程序自带的游戏窗口发送点击，不操作其他窗口。
- 每次点击前读取新的画面，确认所在页面、没有教程或弹窗遮挡、目标唯一且可用；点击后重新读取，确认到了预期的画面。
- 只执行 `assets/input/pipeline_actions.json` 里登记的固定动作。
- 没见过的画面结束当前任务。读不清、超时、画面布局变化或消耗结果不确定时停止，不重试。
- 消耗资源之前安全的返回或重载，在消耗结果不确定之后不再自动执行。

## 资源

| 资源 | 规则 |
| --- | --- |
| ジュエル、付费货币、付费道具 | 不使用 |
| 抽卡 | 不自动执行 |
| 其他背包道具 | 不使用 |
| マニー、铜训练券、Fes 参加权、体力 | 只在勾选了对应任务并打开消耗选项时使用，任务设置里写明「消耗：…」 |
| リカバリーソーダ | 只在周常 Auto 开启「ループ」时使用，每次运行最多补 750 体力 |
| Fes チケット | 不使用 |

这些限制写在 `project_policy.json` 的 `resource_usage` 里，程序运行时按它执行；`tools/check_project.py` 会检查付费货币、付费道具和其他道具三项保持关闭。

## 不做的事

不注入网页脚本或 DOM，不使用浏览器调试接口发送输入，不重放网络请求，不读取账号、密码、Cookie 或浏览器配置，不处理验证码，不绕过反作弊。登录由使用者在游戏窗口内自己完成，登录状态只保存在本机。
