# 自动 Produce 规则

Maa 有三种自动 Produce：由 Maa 逐周决策的 W.I.N.G. 与 say "Halo"，和使用游戏自带オートプロデュース的周常 Auto。两者每一步都先读画面再点击，读不清或结果不确定就停止，消耗体力的点击不会重试。

| | W.I.N.G. | say "Halo" | Auto Produce·周常 |
| --- | --- | --- | --- |
| 入口 | 「Produce」页剧本栏选 W.I.N.G.，点「开始」 | 「Produce」页剧本栏选 say "Halo"，点「开始」 | 「任务」队列里的 Auto Produce·周常，默认不勾选 |
| 谁来玩 | Maa 选每周行动、出每一手牌 | Maa 选每周行动与成長 | 游戏的オート，Maa 负责设置、启动、收取 |
| 体力 | 每局 30，1 倍 | 每局 30，每次 1 局 | 30×次数；开ループ时体力与リカバリーソーダ共 750 |
| 同意消耗 | 点「开始」即同意 | 点「开始」即同意 | 单独的「开始 Auto」开关，默认关 |

两者都不使用ジュエル、付费道具、継続チケット、P 道具、再抽選、スキップ。リカバリーソーダ只在周常 Auto 的ループ里使用（2.5）。

## 1. W.I.N.G.

### 1.1 开始前

- 首页显示「プロデュース中」时，Maa 打开「プロデュース再開」，核对 P 卡和难度，再在ユニット確認里核对 S 卡与 Guest。全部一致才点「再開」，不一致或读不清就停止。Maa 不点「終了」，不放弃进行中的育成。
- 没有进行中的一局时开新局。点「プロデュース開始」前依次核对：育成プロデュース里的 W.I.N.G. 与所选难度、所选ユニット的 6 张卡与设置一致、两个道具栏为空、使用確認是 1 倍且体力恰好减少 30。任一项不符就停止。
- 点击前先写开局记录。上次开局结果不确定时，下次先回首页复核：已在培养中就接手，首页仍是「プロデュース」就记为已复核，按正常流程继续。开局记录读不了时不开新局。
- 游戏内的 3 项 Produce 设置（休む選択時に確認画面を表示、ライブ選択時に確認画面を表示、W.I.N.G.編 ファン数未達成・振り返り警告ポップアップ）ON/OFF 都能处理。记录缺失或超过 7 天时，Maa 在第一个 Hub 打开オプション读取，只读不改。
- 「自动改游戏设置」打开时，Maa 把「未読イベント早送り解除」和「警告ポップアップ」改为 OFF 并保存，之后保持。警告弹窗为 ON 时只处理已知的两种（点「オーディションへ」「振り返りへ」），其他变体停止。
- 「开局前大富豪」：自动 = 推荐编队评分偏低时才玩，指定ユニット不玩；每次 = 每次开新局前玩；关 = 不玩。大富豪每个自己的回合都点パス，不消耗体力，结束后获得アイドルの応援。
- 教程页逐页翻过并关闭，页码读不清则停止。

### 1.2 编队

| 来源 | 做法 |
| --- | --- |
| 指定ユニット（默认） | 用所选ユニット1–20。开局前核对 P 卡，以及上次读到的 S 卡与 Guest（可改为只核对 P） |
| 自动查找编队 | 开新局时在ユニット1–20 里找含这张 P 卡的编队，有上次读到的编队时找同一套，找不到就停止 |
| 推荐编队 | 按「持有卡牌」选 P 卡、4 张 S 卡和 Guest，开新局时改写所选ユニット的 6 个位置 |

- P、S1–S4、Guest 的偶像不能重复，Guest 必须是持有卡，不使用游戏的おまかせ編成。
- 改写编队时按卡面在选卡列表里滚动查找，Maa 可能改动列表的排序键（游戏会记住），不改筛选和升降序。目标卡找不到、读不清或换完后核对不符都会停止。
- 主属性「自动」跟随 P 卡特长（Vocal→Vo，Dance→Da，Visual→Vi）。特长为 Balanced 时需要手动选 Vo/Da/Vi。

### 1.3 每周行动

W.I.N.G. 共 4 季，每季 8 周，之后是 W.I.N.G. 準決勝与決勝。每周可选行动有 3 种课程（Vo/Da/Vi）、3 种工作（ラジオ、トーク、雑誌）、休む和试镜。W.I.N.G. 没有お出かけ。

每周流程：

1. 读季/周、Vo/Da/Vi/Me、粉丝、体力、トラブル率、SP 和 6 个房间（支援人数、预览增量）。关键数值读不清时重读几帧，仍读不清就停止。
2. 房间预览未读到、但乐观估计可能改变选择时，最多额外点选 3 个房间读取预览（只选中，不执行）。
3. 试镜列表取自内置的每季 4 档表，只在要进入试镜时才打开试镜页。
4. 给每个可选行动打分，取最高分。读不到的项记为 0，核心增量读不到的行动不参与排名。
5. 选中的课程或工作会让某项属性到达上限时，先去加点提升上限再重新打分。尚未读到上限时按 500 估算，第一次加点会读取真实上限。
6. 课程/工作：点房间再点「決定」。休息：按休む设置处理确认画面。试镜：打开试镜页翻到该档再点「決定」。

打分项：

| 项 | 内容 |
| --- | --- |
| 主属性成长 | 预览增量×（1−失败率）×（1+大成功期望），超过上限的部分扣除 |
| 其他属性/メンタル | 其他三围只计少量；メンタル低于本季下限（150/200/250/300）时价值提高 |
| SP | 每点 SP 折算为 1 点主属性 |
| 支援 | 房间里支援偶像带来的絆（权重随周数衰减）和事件 |
| 粉丝与试镜 | 课程/工作的粉丝，以及试镜的「胜率×推进本季粉丝目标」，期限越近权重越大 |
| 体力与风险 | 体力消耗与回复，失败和大失败的损失 |
| 约定与テンション | 完成约定的课程加一点分，休息有少量加成 |

先于打分的规则：

- 为达到晋级线（True End 路线第 4 季为 50 万）还需要的试镜胜场数不少于剩余周数时，直接选最优试镜，疲劳也不例外。
- 体調为不調或絶不調时休息。
- 试镜档位与剩余周数无论怎样都达不到粉丝目标时停止，不硬打。
- トラブル率达到「训练失败率阈值」（默认 10%，可选 5/10/15/20）的课程和工作不进入候选，上限固定为 20%。
- 最高分的课程/工作低于「无 S 卡主属性课」收益的 60% 时，按「低收益时的选择」处理：改上无 S 卡的主属性课（失败率达到阈值、已到上限或不如休息时改休息）、休息、或照选最高分。最高分本身是休息或试镜时不触发。

粉丝目标和试镜档位：

| 季 | 晋级线 | True End 路线的季末目标 | 试镜档（粉丝，括号内为需要的ランク） |
| --- | --- | --- | --- |
| 1 | 1,000 | 1,000 | 1,000 / 2,000 / 3,000 / 5,000（E） |
| 2 | 10,000 | 10,000 | 3,000 / 5,000 / 10,000 / 15,000（D） |
| 3 | 50,000 | 100,000 | 15,000 / 20,000 / 40,000 / 50,000（C） |
| 4 | 100,000 | 500,000 | 15,000 / 25,000 / 50,000 / 100,000（B） |

目标「True End」按第 3 列安排，第 4 季累计 50 万粉丝并争取 W.I.N.G. 优胜。目标「各季晋级线」只追到第 2 列。进入试镜需要同时满足ランク、粉丝门槛和已知的胜率估计。课程和工作带来的粉丝足以补齐本季目标时（第 1 季常见），试镜的优先级降低。

「约定处理」：中立（默认）时约定的课程只加一点分，其他行动照常；优先守约时约定课程优先于其他课程与工作，需要的试镜仍排在前面。

### 1.4 试镜与 Live

| 项 | 规则 |
| --- | --- |
| 出牌方式 | 自研策略（默认）：Maa 每回合选牌、选审查员、点 APPEAL 的时机。游戏 Auto：胜率估计达到 Auto 门槛（默认 97%）的普通试镜交给游戏 Auto |
| 攻击目标 | 流行 1 位在场时打它。估计显示按自身属性打更好时改打自身属性。流行 1 位离场后打剩余流行最高的审查员 |
| 选牌 | 倍率×アピール×（属性与审查员一致时 ×2）最高的牌。倍率没读到的牌每回合最多额外点开 2 次读提示。メンタル回復的起始牌和思い出不使用 |
| 收尾 | 名次已无法被追上（领先的星数超过其他人所有剩余可得星数之和），或已拿下流行 1 位的 Top Appeal 且星数领先时，打开游戏的 Auto 打完这场 |
| 读不清 | 手牌或阶段连续读不清时，在游戏 Auto 开关读到 OFF 的前提下交给游戏 Auto 收尾，否则停止 |
| 準決勝・決勝 | 只有第 1 名能通过，不使用「游戏 Auto」选项，由 Maa 出牌，进入前先花完 SP |

「出牌目标」稳拿第一（默认）按上表攻击流行 1 位。选「平衡」时不偏向某位审查员，每手按期望星数选牌和审查员。

强化周间（活动期间）每季最终周多出一场限定试镜，该周不用内置表，改为翻看试镜页。它只是加成：本季目标已达成、出场条件满足、主属性达到页面推奨能力値时才参加，普通试镜已无法达到目标时作为最后机会。S1–S4 可分别关闭。S2、S4 的限定试镜规则无法按自己的打法应对，交给游戏 Auto。这些开关只在活动期间显示。

### 1.5 SP 技能学习

在振り返り面板里加点，策略由「SP 使用策略」决定：

| 选项 | 行为 |
| --- | --- |
| 技能优先（默认） | 顺序见下表 |
| 上限优先 | 主属性上限排到主力 S 卡技能之前 |
| 暂不使用 | 不加点，SP 在育成结束时作废 |
| 手动设置 | 需要加点时停止，由你操作后再点开始续跑 |

| 优先级 | 内容 |
| --- | --- |
| 1 | P 卡的 Live 技能（不论属性）和 P 卡的主属性上限 |
| 2 | 两张主力 S 卡的 Live 技能 |
| 3 | 其他主属性上限，按预计溢出量计价值 |
| 4 | 其他 S 卡的 Live 技能 |
| 5 | 被动 |

- 同一优先级里按「价值/总花费」排序，路径上的前置节点计入花费。P 卡是 SR 或 R 时，它的技能和上限按普通 S 卡处理。
- 主属性下一次增长就会溢出上限时，上限提到最前。没有成长预测时，只有主属性离上限不超过「上限学习阈值」（默认 100）才买上限。
- 默认不学非主属性的 Live 技能。Live 技能最多 4 个，满了先遗忘回复类技能，再遗忘最弱的攻击技能，且新技能要强出 10% 以上才替换。遗忘不可恢复，每次点确认前都核对窗口里的技能名、花费和 SP 前后值，与计划不符就取消。
- 加点时机：每场试镜前、準決勝・決勝前，以及本周行动会让某项属性到达上限且 SP 不少于 20 时。为已规划的 Live 技能目标保留的 SP 不会花在别处。W.I.N.G. 优胜之后不再加点。
- 「结束前使用剩余 SP」（默认关）：準決勝・決勝前最后一次加点，剩余 SP 用于上限和可满足条件的被动。
- 每次加点有点击和读取次数上限。面板读不清、学习结果未确认或点击次数用完时停止，已学的技能保留。

### 1.6 剧情与事件

| 情况 | 处理 |
| --- | --- |
| 剧情 | 用 SKIP 或早送り推进 |
| 有约定（約束）的选项 | 接受。有多个约定选项时停止 |
| 其他选项 | 选「事件默认选项」（默认第 1 项，可选第 2、3 项）。该事件没有这一项时停止 |
| 记者的「密着取材の依頼」 | 固定选「取材を受けない」，不提供接受 |
| 休む确认、ライブ确认、季末、排名、结果页 | 按已知流程点 OK 或下一步 |
| 没见过的画面 | 等待一小段时间，仍认不出就停止 |

### 1.7 道具

不带 P 道具，开局时两个道具栏必须为空。育成中遇到道具窗口只关闭，不使用。检测到道具被使用（不是 Maa 点的）时停止。

### 1.8 失败时

| 情况 | 行为 |
| --- | --- |
| 课程/工作失败 | 属性下降会记录，下周按新数值重新打分。大失败使体力见底时，下周的高失败率会让它休息 |
| 试镜落选 | 不记为胜场。按实际粉丝和剩余周数重新规划，有余量就再打 |
| 粉丝目标无法达成 | 停止并保留进度，由你决定怎么处理 |
| 準決勝・決勝没通过 | 不重试，按游戏进入的结算页面继续 |
| 数值或画面读不清、点击后没有出现预期画面 | 停止，进度保留，点开始可以续跑 |

Maa 不会自己放弃育成。

### 1.9 结束后

- 结算依次经过社長からの評価、フェスアイドル誕生、総合評価、クリア報酬，到「獲得報酬」。「读取结算奖励」（默认开）读取Exスキル，并逐本点开ノウハウブック读取详情，结果写入「结算」摘要。
- 「读取后自动确认」（默认开）：读取完成后由 Maa 按 OK 回首页，再读取新书的完整词条并同步到ノウハウ页。读取不完整时停在「獲得報酬」。关闭后停在该页，由你处理后按 OK。W.I.N.G. 与 say "Halo" 共用这个开关。
- Maa 不点「売却」「移籍」「再抽選」，也不扩充上限。出现这类确认框就停止。
- Maa 自己回到首页后读取新书，并按ノウハウ页的目标判断去留。「自动锁定新书」（默认关）把目标条目库存不足 3 本的书锁定。「自动卖书」目前只列出会卖的书，不点売却。
- 「局数」（默认 1，最多 5）大于 1 时连续开局，要求「读取后自动确认」打开。下一局在这些条件都满足时才开始：上一局由 Maa 按 OK 回到首页、新书已读完、新书没有补上目标缺的条目、锁书结果没有不确定、剩余时间够一局、开局记录没有未决项。
- 一局可能分成几段运行，段间停约 35 秒，进度保留。

### 1.10 默认设置

True End、Middle、主属性自动、局数 1、指定ユニット1。训练失败率阈值 10%，低收益时改上无 S 卡主属性课。SP 技能优先，上限学习阈值 100。约定中立。出牌自研策略、稳拿第一。事件默认第 1 项，不带 P 道具。开局前大富豪自动，自动改游戏设置关。读取结算奖励开，读取后自动确认开，自动锁书和自动卖书关。Beginner 难度不能走 True End，Master 需要在难度里明确选择。

### 1.11 会停止的情况

| 类别 | 例子 |
| --- | --- |
| 开局前 | 已有的育成与设置的 P 卡、难度、编队不符；ユニット里没有设置的编队；道具栏不为空；使用確認不是 1 倍或体力变化不是 30；开局记录读不了 |
| 设置 | Produce 设置读不全；设置页弹出对话框 |
| 读数 | 季/周、体力、SP 等关键数值读不清；画面一直认不出 |
| 计划 | 粉丝目标无法达成；本周计划的行动不在画面上；计划的试镜进不去 |
| 事件 | 选项读不清；没有设置的那一项；多个约定选项 |
| SP | 面板读不清；学习结果未确认；SP 使用策略为手动设置；确认窗口与计划不符 |
| Live | 手牌、阶段或时机条读不清且无法交给游戏 Auto；演出里选中的牌与 Maa 选的不一致 |
| 结算 | 出现売却、移籍、再抽選、上限相关的窗口；没见过的弹窗；「スキルを変更せずに…誕生させますか」 |

## 2. Auto Produce·周常

### 2.1 流程

1. 首页读体力，低于 30×次数就停止。进入プロデュース → オートプロデュース → オートスケジュール。
2. 使用「オート1」一栏。栏为空时由 Maa 设置（2.2）。已有设置的栏只核对，不点「編集」「クリア」。
3. 设置次数（默认 1，可选 1–5）。「上限回数」必须等于这一栏的次数，其他栏有次数就停止。
4. 点「決定」，在开始确认里读「必要スタミナ」前后值，要求前 ≥ 30×次数且后 = 前 − 30×次数，不符就按「キャンセル」后停止。
5. 「开始 Auto」打开时才点「プロデュース開始」。关闭时核对后按「キャンセル」，不消耗。
6. 点击后 60 帧内首页没有出现「オートプロデュース中」，记为结果不确定，不再重按。

### 2.2 Maa 设置的内容

| 项 | 设置 |
| --- | --- |
| 剧本 | 所选剧本（默认 W.I.N.G.）。育成プロデュース列表从上到下是 W.I.N.G.、ファン感謝祭、G.R.A.D.、Landing Point，S.T.E.P. 在「特化」页签。Auto 里没有 say "Halo" |
| ユニット | 所选ユニット1–20，核对页码与编号，并读取ユニット名 |
| 育成方針 | 自动（默认）= P 卡特长（Vocal/Dance/Visual）。Balanced 或读不出特长时保持游戏里的方針。也可固定选一种 |
| 书 | 只有 S.T.E.P. 带 3 本ノウハウブック，其他剧本不带 |
| 道具 | 不带，两个道具栏须为空 |
| 次数 / ループ | 次数见上。ループ未开启时，已打开的「ループする」会被点一次关掉 |

设置完回到オートスケジュール后，Maa 再核对：道具为空、书为 3 本（S.T.E.P.）、ループ状态、ユニット名、次数。

### 2.3 编队

| 选项 | 做法 |
| --- | --- |
| 自动编队（默认） | 日常运行到周常前，先进入 W.I.N.G. 的ユニット編成，把 Maa 选的 P、4 张 S 和 Guest 写进所选ユニット（覆盖原队伍，不消耗），按「←」回到プロデュース選択，再开 Auto。Auto 的ユニット页读到的 P 卡必须等于写入的 P 卡 |
| 指定ユニット | 直接用所选ユニット现有的队伍 |

自动编队需要先扫描「持有卡牌」。没有扫描、凑不齐队伍或写入没有成功时周常任务失败，写入没有成功时之后的任务跳过。选卡规则：

- P 卡避开平时 W.I.N.G. 用的偶像（设置里的 P 卡和上次读到的编队），其余按等级、稀有度、卡号。
- S 卡先看ノウハウ発現マスタリー（同等级数值大的在前），再看本剧本看重的支援技能，再按等级、稀有度、卡号。各剧本都以体力类、マスタリーSP、上限为基础，W.I.N.G. 另计オーディションマスタリー，G.R.A.D. 另计滞在マスタリー，S.T.E.P. 以上限、施設マスタリー、パーフェクトマスタリー为主。
- P、S1–S4、Guest 不重复偶像，Guest 是自己的 S 卡。

### 2.4 带书与词条

| 设置 | 行为 |
| --- | --- |
| 剧本「按目标词条」 | 按ノウハウ页的目标和上次扫描的书库，选 Auto 能拿到最多缺失词条的剧本。同数时按 G.R.A.D.、Landing Point、ファン感謝祭、S.T.E.P.、W.I.N.G. 的顺序，思い出(ノウハウ)类优先 Landing Point 再ファン感謝祭。没有 Auto 能拿的缺失词条时跑 W.I.N.G. |
| 带书：最近設定履歴 | 用最新一组設定履歴的 3 本，点「呼び出し」后 3 槽必须全满 |
| 带书：プリセット1/2 | 点「プリセット」再点对应的「セット」，3 槽必须全满 |
| 带书：ノウハウ页指定 | 用ノウハウ页「设为 Auto 带书」保存的 3 本，在选书页第一屏逐本点选，核对详情的书名和四项属性，三本选齐后核对书页的属性才继续。没有保存时停止 |

- 游戏不允许选与 P/S 同偶像的书，槽位没填满时停止。
- 剧本为 G.R.A.D. 且选了「按目标词条」时，自动编队先按目标词条的ひらめき需求配支援偶像的颜色。
- 「ノウハウ页指定」要求选书页排序为「ノウハウ評価値順」降序，只用第一屏的 15 本，不滚动。

### 2.5 体力与ループ

- 次数 N 消耗 30×N 体力。
- ループ（默认关）打开「ループする」，オート1 重复到上限 25 回，需要体力 750。体力不够时开始确认换成回復アイテム窗口，Maa 用リカバリーソーダ补足。体力已够 750 时出现的是普通确认框，Maa 按「キャンセル」后停止。
- 「ソーダ上限」（450/600/750，默认 450）限定最多补多少体力，首页体力加上限不足 750 就不进入 Auto。同时不超过 `project_policy.json` 里 `stamina_items.max_per_run`。
- 瓶数取能补足所缺体力的最小总量，再取瓶数最少，不超过持有数。只点「+」，每点一瓶都核对「セットするスタミナ」增加的量。
- 必要スタミナ显示 750/750 且「开始 Auto」打开才点「プロデュース開始」，否则按「キャンセル」。ソーダ在开始后才被消耗。

### 2.6 收取结果

任务开始时首页显示「オートプロデュース中」，先收取：

1. 点一次该按钮。已结束时依次出现「オートプロデュース終了」OK、「オートリザルト」OK，Maa 各点一次。结果页的保護、移籍、売却不碰。
2. 回首页后弹出的「ミッション達成」「イベント累計報酬獲得」交给通用的回首页流程，最多处理 2 次，活动页只经过不领取。
3. 首页恢复「プロデュース」后，按 2.1 的流程开下一局。
4. 还没结束时出现「オートプロデュース確認」，Maa 读取残り時間后按「キャンセル」并停止，不按「終了」和「スキップ」。
5. 点击后没有反应，或某一步超过 60 帧，停止且不重试。

Auto 进行中首页没有「プロデュース」按钮，期间不能开 W.I.N.G.。日常运行里周常 Auto 单独成段，收取结果后读取新书，书和命中的目标词条记在本机的词条记录里。读书时只报告保留/去留计划，不锁书不卖书。

### 2.7 会停止的情况

| 类别 | 例子 |
| --- | --- |
| 体力 | 首页体力不足；开始确认的「必要スタミナ」前后值与次数不符；体力不够而未开ループ |
| 栏位 | 道具栏不为空；书不是 3 本；其他栏有次数；ユニット名或剧本与核对结果不符 |
| 设置 | 次数点击后读数没有按预期变化；ループ状态改不过来；育成方針切换后行上仍不同；剧本列表里目标在已显示的剧本上方 |
| 带书 | 槽位没填满；选书页排序不对；第一屏找不到目标书；选完后属性与保存的不一致；书页进来时已有书 |
| 编队 | 自动编队没有写入成功；ユニット页读到的 P 卡与写入的不符 |
| 画面 | 出现ノウハウブックの教程、没见过的画面，或点击后页面久不切换 |
| 状态 | 已有 Auto 在进行；开始后没有看到「オートプロデュース中」 |

「开始 Auto」关闭时，运行在开始确认处按「キャンセル」结束，原因为未允许消耗。

### 2.8 默认设置

开始 Auto 关。剧本 W.I.N.G.，自动编队，ユニット1，育成方針自动，带书最近設定履歴（仅 S.T.E.P.）。次数 1，ループ关，ソーダ上限 450。周常「フェスアイドルを誕生させよう」等任务的完成数不影响 Maa 开几次，次数由你设置。

## 3. say "Halo"

2026-11 实机跑完四局（掘书线、おまかせ編成，第 3 季末放弃 Final Live；后三局用自动编队，从首页开局到报酬页全由 Maa 完成；后两局解散队伍后チーム完成度到 100%）。只做掘书线。P 偶像与编队沿用 W.I.N.G. 的设置。中途关掉引擎再开始，本局已做的事（施設効率相談、成長、粉丝）会接着用。

### 3.1 开局

- 特化プロデュース → say "Halo"編 → ユニット（与 W.I.N.G. 相同的核对）→ ノウハウブック → 道具 → 使用確認。
- 带书：おまかせ編成（默认）、最新一组設定履歴、游戏内プリセット1/2，或「ノウハウ页指定」：ノウハウ页 say "Halo" 推荐书旁点「设为 Halo 带书」。指定书时选书页须按ノウハウ評価値降序，书要在第一屏（前 15 本）；Maa 按評価値找书，核对书名与 Vo/Da/Vi/Me 后放入。读到第 1 格已放书才点「決定」。
- 道具栏为空、1 倍、体力恰好减少 30 才点「プロデュース開始」。
- 进行中的 say "Halo" 局：再開对话框里 P 偶像一致，Hub 的ユニット確認里 P、S、Guest 与设置一致才继续。

### 3.2 掘书线

| | |
| --- | --- |
| 目的 | 让书带上 施設効率相談 / +、パッシブスキル延長 / +、昂揚 |
| 每周 | 施設効率相談 / + → 提高チーム完成度的合同练习 → 成功率 100% 的试镜 → 体力低时休息 → 同行偶像给アドバイス最多的课程。施設効率相談 / + 还缺アドバイス且親愛度已到 50 时，课程排在试镜前（课程一周给 2–5 个，试镜只给 1 个ベスト） |
| 成長 | 第 2 季起每周一次：Vo/Da/Vi 用各自的点数补属性与上限，集中力不花；目标含施設効率相談+ 时親愛度买到 80，只要施設効率相談 时买到 50 |
| 勧誘 | 默认候选已在队里时，选第一个没勧誘的候选再点チームに勧誘 |
| 解散 | 第 2 季起（目标含チーム完成度时）チーム情報 →「チーム編集」→ 逐个「離脱させる」，只留 P 偶像，完成度涨得快 |
| 目標ライブ | 选成功率最高的一项 |
| 结束 | 目标都拿到，或到 Final Live 时长按「諦める」放弃（书与 Fes 偶像照常产生）；スキル一括変更 点キャンセル，不改技能 |

掘书线的目标取自ノウハウ页的想要列表：列了 施設効率相談 / + 就做；パッシブスキル延長+ 或 昂揚 → チーム完成度 100%，パッシブスキル延長 → 51%；没列ファンの声援时，试镜让粉丝总数（日程页右下）留在 9 万以下（课程、工作、目標ライブ 也给粉丝）；目標ライブ 也给粉丝，总数已过 10 万就不再限制。列表里没有 say "Halo" 条目时用默认目标（施設効率相談 / +、完成度 100%，不限粉丝）；有条目但掘书线一项都做不了时不开始。「Produce」页带书下方显示本次目标。
