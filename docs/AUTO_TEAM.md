# 自动编队

Maa 在两处自动组队：W.I.N.G.（「Produce」页）的「推荐编队」，和周常 Auto（任务页「Auto Produce（周常）」）的「自动编队」。两处都只从「持有卡牌」里选卡，把结果写进你选的一个ユニット（共 20 个，ユニット1–20），不使用游戏自带的推荐編成。

| | W.I.N.G. 推荐编队 | Auto 自动编队 |
| --- | --- | --- |
| 入口 | 「Produce」页，编队来源选「推荐编队」 | 「Auto Produce（周常）」，编队选「自动编队」（该任务的默认值；任务本身默认不勾选） |
| P 卡 | 你选 | Maa 选 |
| S1–S4、Guest | Maa 按 32 周成长评分选 | Maa 按 Auto 规则排序选 |
| 写入时机 | 开新局时写进所选ユニット（默认ユニット1） | 每次运行里，Auto 开始前写进所选ユニット（默认ユニット1） |
| 已在进行的 Produce | 不改编队，核对 P 与 S/Guest，不一致就停止 | 不适用 |
| 消耗 | 换卡阶段不消耗；开新局消耗体力 30 | 换卡阶段不消耗；Auto 开始消耗体力 30×次数 |

两处另有「指定ユニット」来源：你在游戏里自己编好队，Maa 不改它。W.I.N.G. 会核对所选 P（有上次读到的编队时一并核对 S/Guest），还可以再开「自动查找编队」，在ユニット1–20 里找含所选 P 的编队（最多点 24 次），找不到就停止；Auto 直接使用该ユニット现有的队伍。本文只讲会改写ユニット的两种。

## 共同规则

- 一队 6 张：P 卡、S 卡 4 张（S1–S4）、Guest（第 5 张 S 卡）。Guest 不参加试镜，只提供成长。
- 同一偶像在 P、S1–S4、Guest 里只出现一次。
- P、S、Guest 都必须在持有卡牌里，Guest 也必须是你持有的 S 卡。没有持有的卡不会被选，卡牌资料里有也一样。
- 同一张卡不能占两个位置。
- W.I.N.G. 换卡前会再检查一遍：缺 P、S 不足 4 张、偶像重复、Guest 未持有，任何一项不符就停止，ユニット保持原样。Auto 在选卡时就按这些规则选。

## 持有卡牌

### 读取与确认

- 资源页「扫描持有卡」：Maa 滚动アイドル一覧的サポートアイドル、プロデュースアイドル两个标签，只读。列表开着「絞り込み」时停止。
- 每张卡读到三样：卡的身份（缩略图匹配），Lv（只有 S 卡，读「Lv.NN」），凸数（卡左侧星星，0–4；P 卡只有凸数）。读出的 Lv 超过该稀有度在该凸数下的上限时，这张读数被拒绝。
- 也可以在资源页「编辑持有卡牌」手动标记持有，在卡片详情里填 Lv/凸。

| 读数 | 处理 |
| --- | --- |
| 可信度 ≥ 70%，且是新卡、空值，或上次自动写入的值 | 自动写入，可用「撤销本次自动采用」退回 |
| 可信度 < 70% | 进「需要你确认」，点确认或修改才写入 |
| 与你已填的值不同 | 进「需要你确认」，标「与已填写不同」，不会被覆盖 |
| 没认出的格子 | 不加入，只显示未识别的数量 |

- 来自较早录制的读数，可信度再减 3%。
- 「忽略此识别」之后，同一读数不再提示。
- 可信度由缩略图匹配得分、与其他偶像的差距、边框稀有度、星星清晰度和 Lv 文字识别得分合成，离接受阈值越远越高。

### 两个流程用到的字段

| 字段 | W.I.N.G. 推荐编队 | Auto 自动编队 |
| --- | --- | --- |
| P 卡 | 你选的 P 必须在持有卡牌里，且有凸数 | 持有卡牌里的全部 P 卡 |
| S 卡 | Lv 和凸数都已知的才参与 | 全部持有 S 卡参与。Lv 取扫描值；没有就取凸数对应的等级上限（没有凸数记录按 0 凸）；卡牌资料里没有上限的按 0 |
| 卡牌资料 | 卡必须在本地卡牌资料里（资源 → 卡资料 → 下载卡资料），没有的不参与 | 同左 |
| 尚未确认的扫描读数 | 补给没有任何已保存 Lv/凸 的卡，不改你已保存的值；扫描里看到、还没加入持有卡牌的卡也会被算进去，入选后开始前检查会提示「不在持有卡牌中」，确认后才能开始 | 不使用，只看已保存的值 |
| 数据缺失时 | 该卡不参与，可用的卡不够时显示「暂无推荐」 | 缺 Lv 的卡排在后面 |

卡牌资料更新是单独的操作；读取卡牌资料时距上次检查超过 12 小时，会自动检查一次更新。推荐的计算本身在本机完成，不连接游戏，不发送操作。

## W.I.N.G. 推荐编队

### 使用顺序

1. 在资源页扫描持有卡，并下载卡牌资料。
2. 在「Produce」页选 P 偶像（必选，只能从持有 P 卡里选），编队来源选「推荐编队」，选要覆盖的ユニット。
3. 推荐自动开始计算。完成后六张卡自动写入设置，标「已采用」和「估算」。换了 P 偶像、主属性或持有卡牌后会自动重算一次，也可以点「推荐」手动重算。输入不变时结果相同（固定随机种子，平局按卡 ID）。计算超过 5 分钟按失败处理。
4. 点开始即同意覆盖ユニット，没有确认框。

推荐不可用时开始会被禁用，并写明原因：需扫描持有卡；持有的 S 卡不足 5 名偶像；所选 P 偶像不在持有卡中；P 卡缺少 Lv/凸 或卡牌资料；无本地卡牌资料。

### 主属性

主属性选「自动」时，取 P 卡自身的特长（「Visual & Dance」取第一个，即 Vi）；手动选 Vo / Da / Vi 时按所选属性。P 卡特长是均衡或读不出时，需要自己选。推荐只按这一个属性搜索，不搜索双属性队。

### 哪些卡能入选

- P：你选的那张。持有卡牌里有凸数即可；资料里多数 P 卡没有 True End 资格标记，所选 P 按「有 True End」计算。
- S 卡出场（S1–S4）：Lv、凸数、卡牌资料齐全，且自带 Live 技能（所持ライブスキル）已知。
- Guest：同上，但自带 Live 技能未知的卡也可以当 Guest。
- S 卡和 Guest 里不能有与 P 同偶像的卡，五张 S 卡彼此也不同偶像。
- 除 P 偶像外，可用的 S 卡要有至少 5 名不同偶像。

自带 Live 技能优先用 Wiki 记录。没有记录的 S 卡，按稀有度、获取方式和发布日期推算：

| 卡 | 自带技能（Lv1） | 升级 |
| --- | --- | --- |
| R | アピールⅡ 1.5 倍 | 无 |
| SR | アピールⅢ 2.0 倍（2024 年起的 Present SR 为Ⅳ 2.5 倍） | 无 |
| SSR 常驻、活动，以及 2020-01-31 前的限定 | アピールⅣ 2.5 倍 | Lv60/65/70/75/80 各 +0.1，Lv80 为 3.0 倍 |
| SSR 限定、Fes 奖励、有偿、联动、Situation Drama（2020-01-31 起） | アピールⅤ 3.0 倍 | 同上，Lv80 为 3.5 倍 |
| Twilight SSR | アピールⅥ 3.0 倍 | 同上，每级另加该属性 +5%（3 回合） |
| UR | アピールⅦ 3.5 倍 | Lv70/75/80/85/90 各 +0.1 并加 +5%，Lv90 为 4.0 倍 |

属性取该卡最高等级时 Vo/Da/Vi 中最高的一项；三项相等是エクセレント。两项并列的旧卡、N 卡、没有属性数据的卡不推算，保持未知，只能当 Guest。SSR 里没有样本的获取方式按 2.5 倍档计。推算值可能与个别卡不符。

### 怎么选

1. 出场位按角色（主攻、副攻、属性成长、SP、回体、上限、试镜成长、其他）、Guest 位按成长、SP、上限、回体，各取评分最高的 10 张，出场位再补 8 张 Live 面板最强的卡。
2. 逐个位置做束搜索（束宽 60，投影最多 3000 次，只评估前 3 队），每个候选队按 32 周成长重算整队，不给单张卡固定分数。搜索有界，不保证全局最优。
3. 五张 S 卡定下后，Maa 逐张试换到 Guest 位，取整队分最高的分法。分数相同时，比较未封顶的试镜手牌，仍相同则保留搜索时的分法。
4. 整队分（0–100）：

| 项 | 分值 | 满分条件 |
| --- | --- | --- |
| 主属性 | 40 | 预计值达 900 |
| Me | 15 | 预计值达 350 |
| SP | 15 | 累计 SP 达 450 |
| 技能 | 15 | 一半看 P 学到的技能倍率（最强一张按 6 倍封顶，前三张合计按 15 倍封顶），一半看试镜牌组（P 的技能加 4 张出场 S 卡自带 Live 技能）在第 33 周的手牌强度，以三次出牌能打满决赛评委（72000）为满分 |
| 被动 | 5 | 学到的被动每回合期望加成达 30% |
| 50 万粉丝路线 | 10 | 路线可行得满分 |

这是估计值，不是 True End 概率，也不含战斗模拟。P 与 5 张 S 卡的成长、SP 路径、技能计划、上限和被动都按整队重算；稀有度与系列标签本身不加分。

### 推荐条上看到什么

- 每张 S 卡下的标签：自带 Live 的属性与倍率（如「Vo 3.5倍刀」）、属性课、SP、上限、回体、组合、省体，每张最多 4 个。
- 主属性后的流派标签：单属性；オデマス（有 2 张以上オーディションマスタリー卡）；组合（某个组合全员出场且有卡的「<组合>全員」被动生效）。
- 「其他推荐（N）」：最多 2 套卡组不同的队，标明换了 Guest 还是换了几张 S 卡，并写出属性、SP 的增减。两套都与最优队同一流派时，第二套换成另一流派里分数最高的队。点「使用这队」改用它。分数与最高分相差不到 1 分的标「基本持平」。
- 「训练后可加入推荐」：最多 3 张持有 S 卡，练到当前凸数的等级上限后能让整队分提高 0.3 以上，写明目标等级和换下的位置。只算练级，不算突破；上限等级的数据缺失的卡不参与。
- 「推荐理由」：主属性预计值、SP、50 万粉丝路线是否可行和整队分。

「开局前大富豪」选「自动」时，已采用的推荐分低于 75，或 50 万粉丝路线不可行，开新局前会先玩一局大富豪。

### 回退

True End 推荐器的资料不够时（没有卡牌资料、可用 P 或 S 不足、数据不全），改用旧评分。旧评分要求 P 卡有 True End 标记、至少 3 张 S 卡的 Live 技能属性与主属性一致，而这条路径只提供稀有度、Lv 和凸数，所以回退得不到队伍，界面显示「暂无推荐」和原因。回退选出的 P 与你选的不同时也不采用。

### 开始后

- 开新局：Maa 进入所选ユニット，按下面「写入ユニット」的方式改成推荐编队，整队核对一致后才点「次へ」，再开始 Produce。
- 游戏里已有进行中的 Produce：不改编队。先核对继续窗口里的 P 偶像与 P 卡，再打开ユニット確認，核对 P 卡和这套推荐的 S、Guest，任何一项不一致或读不清就停止，不放弃进度。

## Auto 自动编队

### 流程

1. 日常运行里，先跑「Auto Produce（周常）」之前的任务。
2. 一段只编队的 W.I.N.G. 运行（没有消耗授权，到不了开始）：首页 → プロデュース選択 → ユニット編成 → 改写所选ユニット → 核对 → 按一次「←」回到プロデュース選択。
3. Auto 设定时，ユニット页读到的 P 卡必须等于刚写入的 P 卡，否则停止，不点「次へ」。
4. 之后的任务照常运行。所选队伍（P、S1–S4、Guest、ユニット、结果）记在这次运行的读数里。

编队默认写入ユニット1。想保留自己的ユニット，先在「ユニット」网格里选别的编号。

### 选卡规则

按顺序：

1. P 候选：持有的 P 卡中，偶像不是「平时 W.I.N.G. 的 P 偶像」的卡。平时的 P 偶像 = 「Produce」页所设 P 卡的偶像，加上最近一次 W.I.N.G. 运行读到的ユニット編成里的 P 偶像。持有的 P 卡全都属于这些偶像时，仍从中选。
2. P 排序：等级（P 卡没有等级，通常相同），再按稀有度（UR > SSR > SR > R > N），最后卡号小的优先。
3. S 排序，逐级比较：
   1. ノウハウ発現マスタリー 在该卡当前等级的数值，大的优先（只有少数 S 卡有这项技能）；
   2. 本剧本看重的支援技能得分（见下表）；
   3. 等级；
   4. 稀有度；
   5. 卡号小的优先。
4. 按 S 排序从前往后取，跳过偶像已入选（包括 P 的偶像）的卡，取满 5 张。前 4 张是 S1–S4，第 5 张是 Guest，都是你持有的卡。
5. 当前 P 候选凑不满 5 个不同偶像的 S 卡时，换下一张 P 候选。

剧本技能得分：卡上已解锁的支援技能（解锁等级不高于该卡当前等级），按种类计分，同一种只算一次，不区分 Vo/Da/Vi，分值如下。

| 剧本 | 体力类（体力サポート、各マスタリー体力） | マスタリーSP（含ユニット） | 上限（含ユニット） | 其他 |
| --- | --- | --- | --- | --- |
| W.I.N.G. | 3 | 2 | 1 | オーディションマスタリー（SP、属性）各 1 |
| ファン感謝祭 | 3 | 2 | 1 | |
| G.R.A.D. | 3 | 2 | 0 | 滞在マスタリー 1 |
| Landing Point | 3 | 2 | 1 | |
| S.T.E.P. | 3 | 2 | 3 | 施設マスタリー 3，パーフェクトマスタリー 2，滞在マスタリー 1 |

剧本取任务里的「剧本」选项；选「按目标词条」时，先按ノウハウ页的目标换成具体剧本再选卡。

G.R.A.D. 的ひらめき颜色由サポート偶像决定，每个偶像固定一色（Vo/Da/Vi/Me）。「按目标词条」选到 G.R.A.D. 时，目标词条所需的ひらめき会按最大余数法分成 5 张サポート的颜色配额。选 S 卡时先按上面的顺序补满配额，其余位置再按原顺序补。

### 失败时

编队失败只让「Auto Produce（周常）」失败，其他任务照常运行。失败原因按代码原样显示：

| 显示 | 原因 |
| --- | --- |
| `auto_team_owned_cards_missing` | 没有持有卡牌，或没有 P 或 S 卡：先扫描持有卡 |
| `auto_team_no_p_card` | 没有可用的 P 卡（持有的 P 卡都没有卡牌资料） |
| `auto_team_not_enough_s_cards` | 凑不齐 5 个不同偶像的 S 卡 |
| `auto_team_p_card_mismatch:<卡号>` | Auto 设定页读到的 P 卡与写入的不同 |
| `auto_team_p_card_unread` | 读不到 Auto 设定页的 P 卡 |
| `auto_team:<原因>` | 编队阶段中途停止，原因同下表 W.I.N.G. 的停止码；之后的任务跳过（游戏可能还停在设定页） |
| `startup_failed` | 没回到首页（如维护中），不编队，Auto 和之后的任务跳过 |

## 写入ユニット

两处共用同一套换卡过程。游戏每选一张卡就保存，没有保存按钮，所以中途停止时已换好的卡会保留。

- 顺序：S1–S4、Guest，最后换 P。S 卡按集合处理：目标 S 卡已经在某个 S 槽里就不动，其余槽按配置顺序补。
- 第一次打开サポート列表时，先逐张确认要换的支援卡都在列表里、都在 Maa 能点的位置（只读，必要时向下滚）。缺任何一张，在换第一张前停止。
- 在列表里只读滚动查找目标卡：每次打开最多滚 30 步，每步等画面稳定，相邻两帧至少共有一张卡，滚不动视为到底。找到后点一次，点后读回该槽必须是目标卡，否则停止。一次编队最多改 6 个位置。
- 排序：W.I.N.G. 打开サポート列表时，按目标卡的主属性换排序键（▼降順），让目标排在第一页。目前只有 Dance順 能切换，Vocal順、Visual順、メンタル順 会跳过排序，直接滚动查找。Auto 固定排成 Lv順 ▼降順。排序会被游戏保存，并与 S 卡训练列表共用，Maa 不会改回原来的排序，运行记录里留有原排序。
- 换入的卡与ユニット里另一张卡同偶像时，游戏会弹确认框并清空那个位置。Maa 对刚点的卡按一次 OK，再补上被清空的位置。同一位置的确认框第二次出现，或不是刚点的卡引起，就停止。Maa 读出要换入的偶像已在另一个位置时，先换不冲突的位置（例如要换入的 S 卡正是旧 P 的偶像，就先换 P）；所有待换位置都冲突才停止。
- 全部换好后整队核对一致才继续：W.I.N.G. 点「次へ」，Auto 点「←」回到プロデュース選択。

换卡阶段的停止都发生在开始 Produce 之前，不消耗体力，也不重试。

| 停止原因 | 提示（节选，均带「已停止；未消耗」） |
| --- | --- |
| 编队不符合规则 | 推荐编队不符合编队规则（重复偶像或 Guest 未持有）；ユニット未改动 |
| 要换的卡不在选卡列表里 | 推荐的卡不在选卡列表里；ユニット未改动。请更新持有卡后重新推荐 |
| 要换的卡在未验证的位置，或滚轮不可用 | 推荐的卡不在选卡列表第一页；ユニット未改动 |
| 上面两项在换 P 卡时才发现 | 推荐的 P 卡不在选卡列表里（或第一页）；ユニット里已换的卡保留 |
| 列表停在卡与卡之间、同一张卡出现两次、一次滚动太多、一直在动、翻找次数用完、读不清 | 选卡列表相应的提示 |
| 点卡后仍在列表、换卡后读到的卡不对、改完后整队核对不一致 | 请在游戏里核对ユニット |
| 推荐的偶像已在ユニット的另一个位置 | 请在游戏里核对ユニット |
| ユニット有空位、一直在加载，或有卡读不清 | ユニット有空位或一直在加载 / ユニット里有卡读不清 |
| 排序窗口读不清、排序没生效 | 关掉排序窗口（或核对排序）后再开始 |

## 示例

**W.I.N.G.：同一偶像的两张 S 卡。** 你持有同一偶像的两张 S 卡，一张带 SP 技能，一张带回体技能。队里最多放其中一张。推荐器分别算「带 SP 的入队」和「带回体的入队」的整队分，取高的那一队。

**W.I.N.G.：Guest 位。** 五张 S 卡里，一张自带 Live 倍率低，但有 SP 和上限技能。把它放在 Guest 位时整队分更高，Maa 就把它放进 Guest，四张 Live 倍率高的卡出场。五张在 Guest 位和出场位之间互换后分数相同，则比较未封顶的试镜手牌。

**W.I.N.G.：缺 Lv 的卡。** 一张持有的 S 卡扫描没读到 Lv。它不参与推荐，其余卡照常计算。在资源页重新扫描，或在卡片详情里填上 Lv 和凸数后，推荐会自动重算，也可以点「推荐」手动重算。

**Auto：选 P。** 持有 A 偶像 SSR、B 偶像 SSR、C 偶像 SR 三张 P 卡，平时 W.I.N.G. 用 A。候选只剩 B 和 C，B 的稀有度更高，选 B。B 偶像的 S 卡不再入选，C 偶像的 S 卡仍可入选。

**Auto：选 S。** 持有 D 偶像的两张 S 卡，都带ノウハウ発現マスタリー，在各自的等级下数值一张高一张低。数值高的排在前面，它入选后，D 偶像的另一张被跳过。没有这项技能的卡排在有这项技能的卡之后，彼此按剧本技能得分、等级、稀有度、卡号排。第 5 张入选的卡当 Guest。
